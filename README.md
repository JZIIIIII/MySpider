# PDD Collection Tool

## 项目简介

PDD Collection Tool 是一个支持 **拼多多、淘宝、京东、1688** 四大电商平台的商品信息采集工具。它支持抓取商品的标题、价格、销量、评论数、店铺链接、图片等信息，并将结果以 Excel 格式保存。本工具基于 Python 构建，融合了 Selenium、pyquery、Pillow 等技术栈，具备多种反爬和自动化特性。
本代码已经经过脱敏 只做为展示使用 无法直接运行 只做参考

## 功能特性

- **支持四大平台**：淘宝、拼多多、京东、1688。
- **商品信息爬取**：抓取商品标题、价格、销量、评论数、店铺名、是否包邮等字段。
- **图片下载与插图**：可下载商品主图并插入 Excel 文件中。
- **防反爬机制**：
  - 使用 `undetected_chromedriver` 和 `selenium-wire` 绕过浏览器指纹识别。
  - 模拟用户行为滚动与点击，规避简单反爬。
- **风控检测功能**：
  - 自动识别平台封控提示（如滑块、冻结提示、登录中断等），中止采集并提示用户。
- **增量式哈希采集**：
  - 基于哈希值判断是否重复采集商品，支持断点续抓，避免重复写入，提升效率与稳定性。
- **懒加载支持**：自动滚动页面，触发平台的懒加载机制，确保加载完整商品数据。
- **Excel 导出**：将抓取结果保存为带图 Excel 文件，支持字段自定义与样式优化。
